## Project Description

This project focuses on detecting plant diseases using image processing techniques. The system will analyze images of plant leaves to identify signs of disease and classify them based on their visual characteristics.

## Project Goal

To explore how image processing techniques can be used to support the detection and classification of plant diseases from leaf images.
